# FenriX

**AI-powered interactive games for analytics and decision science.**

FenriX builds live, competitive browser games that put predictive models to the test in real-time, high-pressure environments. Every game is developed using agentic AI frameworks, from concept to deployment.

## What We Do

We design and ship multiplayer games where 30-50+ players compete simultaneously. Players make strategic decisions powered by their own predictive models, and the leaderboard tells them instantly whether their analysis holds up against the competition.

## How We Build

Every project is developed using AI-first workflows. Our team uses Claude, Cursor, Codex, and other agentic coding tools to move from idea to deployed product in weeks, not months. The tech stack is intentionally lean: React, Firebase, Python, and whatever gets the job done fastest.
